# UNIX — персональный ИИ под вашим контролем

> **Не просто искусственный интеллект. Твой собственный.**

**UNIX** — разрабатываемая интеллектуальная среда для Windows, ориентированная на локальную работу, долговременную память, агентные инструменты и постепенную персонализацию под владельца.

Идея UNIX — дать человеку не только чат с нейросетью, но и помощника, который со временем лучше понимает задачи и предпочтения пользователя, сохраняет полезный опыт и действует **в пределах предоставленных разрешений**.

## Принципы UNIX

### 1. Локальность по умолчанию
Базовый сценарий — работа модели и хранение пользовательских данных на собственном устройстве. Сетевые функции не должны быть обязательным условием для локального диалога. Конфиденциальные сведения не должны передаваться внешним сервисам без явного разрешения.

### 2. Память и непрерывность опыта
UNIX проектируется как система, способная сохранять важный контекст, предпочтения, подтверждённые знания и историю взаимодействий. Цель — чтобы смена версии приложения или базовой модели не означала потерю всего накопленного опыта.

### 3. Обучение, понятное человеку
Одна из долгосрочных целей — позволить пользователю обучать помощника без необходимости разбираться в Python, датасетах и тонкостях машинного обучения: показывать примеры, исправлять ошибки и проверять результат.

**Важно:** сохранение исправления в памяти, подключение навыка и дообучение весов модели — разные механизмы. UNIX стремится сделать их удобными, не смешивая технические понятия и не обещая мгновенного переобучения любой модели.

### 4. Действия с разрешения владельца
Агенты должны работать с понятными границами доступа, подтверждением значимых действий, журналированием и возможностью остановки. Ответ модели сам по себе не является доказательством успешного выполнения операции.

### 5. Индивидуальность без навязанной зависимости
Персональный UNIX может иметь собственный стиль общения, голос, историю и настраиваемые привычки взаимодействия. Его задача — быть полезным и комфортным помощником, уважая автономию человека, а не искусственно удерживая его внимание.

## Архитектурное направление

```text
                   UNIX INTERFACE
                         |
                     UNIX CORE
                         |
       +-----------------+-----------------+
       |                 |                 |
   LOCAL MODEL        MEMORY          AGENT SYSTEM
   GGUF / runtime    context /         tools / permissions
                     knowledge
       |                 |                 |
       +-----------------+-----------------+
                         |
                USER-CONTROLLED ACTIONS
```

Архитектура развивается модульно: модель, память, голос, инструменты и пользовательский интерфейс должны иметь чёткие границы ответственности.

## Что исследуется дальше

- **Подтверждённое обучение:** накопление проверенных примеров, оценка ошибок и перенос полезного опыта.
- **Адаптеры моделей:** эксперименты с LoRA/QLoRA, тестирование и безопасный откат.
- **Режим разработчика:** расширенные настройки, собственные модели и предупреждения о рисках изменений.
- **Персональные агенты:** специализации, характеры и визуальные представления.
- **Наблюдаемость:** понятные журналы, визуализация событий памяти и работы инструментов без имитации буквального «чтения мыслей» модели.
- **Свобода обновлений:** сохранение пользовательских данных, контроль обновлений и совместимость версий там, где она технически возможна.

Эти направления **не являются обещанием готовых функций или дат релиза**.
